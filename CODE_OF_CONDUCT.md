# Code of Conduct

Nerva is an open-source project for careful, security-sensitive developer tooling. Participation requires technical rigor and respect for the people behind the work.

## Expected behavior

- Be constructive, specific, and respectful.
- Critique ideas and evidence, not people.
- Respect different levels of experience, communication styles, and backgrounds.
- Keep security reports, credentials, prompts, screenshots, local paths, and private task data out of public discussions.
- Accept maintainer decisions about scope, safety boundaries, and release evidence.

## Unacceptable behavior

- Harassment, discrimination, threats, sexualized conduct, or personal attacks.
- Publishing another person's private information without permission.
- Deliberately bypassing Nerva's security boundaries or encouraging unsafe deployment.
- Repeated disruption after a maintainer has asked for a behavior to stop.

## Scope and enforcement

This code applies in repository discussions, issues, pull requests, reviews, and other spaces where someone represents Nerva.

Maintainers may edit or remove contributions, lock discussions, issue warnings, or temporarily or permanently restrict participation. For a confidential conduct report, use [GitHub Private Vulnerability Reporting](https://github.com/blancmathis/nerva/security/advisories/new) and prefix the title with `[conduct]`. Do not include sensitive material in a public issue.

Maintainers will review reports privately, avoid unnecessary disclosure, and act proportionately to the behavior and its impact.
